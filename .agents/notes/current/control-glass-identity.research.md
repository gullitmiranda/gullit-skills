# Research: "control-glass" identity and GitHub Agent Skills

Accessed: 2026-08-27

## Scope and bottom line

This is a public-source identity check for the label "control-glass," described as a woman appearing in an X-post video. The X post URL was not supplied, so the label was tested against X handle variants, the apparent company's official site, GitHub, and first-party Agent Skills repositories. No identity was inferred from facial appearance.

**Bottom line:** The strongest public match is **Control Glass A&S / Control Glass Acústico y Solar, S.L.**, a Spanish specialty-glass company and the owner of the X account `@ControlGlass`. This is a high-confidence match for the organization, but only a medium-confidence interpretation of the user's label because the supplied term is hyphenated and the original post is unavailable. A separate, high-confidence public identity uses X `@poteto` and GitHub `poteto`, both cross-linked as **lauren**. Cursor's official `pstack` plugin names **Lauren Tan** as its author and includes public `SKILL.md` files, including `poteto-mode`. This establishes public Agent Skills authorship for Lauren Tan in GitHub-hosted Cursor materials. It does **not** connect Lauren Tan or `@poteto` to the Control Glass campaign/video. The woman remains unresolved, and no available first-party source shows her saying `poteto` or another username.

## Confirmed facts

### X and official-site evidence

- The public X profile [@ControlGlass](https://x.com/ControlGlass) is named **Control Glass A&S**, describes itself as a specialty-glass processor from Spain, lists Teruel, Spain, and links to `controlglass.com`. Confidence: **High**.
- The account published two public video posts on April 15, 2020: [the 78-second `#Esto no tiene que parar` post](https://x.com/ControlGlass/status/1250329279012855813) and [a 45-second companion post](https://x.com/ControlGlass/status/1250455630990712832). The visible campaign context includes Teruel and `VOLVEMOS A CONTROLGLASS` / `#ESTO NO TIENE QUE PARAR`. Confidence: **High** for the posts and campaign association.
- Control Glass's [official campaign page](https://www.controlglass.com/estonotienequeparar/) is dated April 15, 2020 and is titled `EstoNOtienequePARAR`. Its [official WordPress API record](https://www.controlglass.com/wp-json/wp/v2/posts/6319) links the page to a YouTube video and campaign images. The YouTube upload is not currently available through the normal public YouTube page, but the official site's record preserves the original embed. Confidence: **High** for the campaign association; **limited** for the unavailable YouTube copy.
- The official [legal-information page](https://www.controlglass.com/legal-info) identifies the business as **Control Glass, Acústico y Solar, S.L.** The official [team page](https://www.controlglass.com/team/) lists staff and roles, including female staff entries in Quality & Research and Administration, but does not say who appears in the campaign video or credit an actor, employee, narrator, or presenter. Confidence: **High** for what the pages state; **unresolved** for any connection to the video woman.
- The similar X account [@control_glass](https://x.com/control_glass) is a separate profile displayed as "Control Glass," based in Madrid, with no public posts. It does not establish a link to the woman or to the Teruel company. Confidence: **High** for the profile distinction.

### GitHub and Agent Skills evidence

- GitHub's exact user search for [`control-glass`](https://api.github.com/search/users?q=control-glass) returned zero users. Confidence: **High** for that public search result at the access date.
- A GitHub account named [`controlglass`](https://github.com/controlglass) exists, but its public profile says it has no public repositories, no public bio, and no visible link to Control Glass A&S. The public repositories endpoint also returns an empty list: [`/users/controlglass/repos`](https://api.github.com/users/controlglass/repos?per_page=100). This account is not evidence that the X company's staff, the video woman, or the company owns it. Confidence: **High** for the profile state; **low** for any identity relationship.
- Exact-name GitHub searches for the company-listed female staff entries produced no matching public users, repositories, or commit results in the checks performed. This is negative search evidence only, not proof that no person with those names has an account under another name or a private/unindexed repository. Confidence: **Medium** for the search result; **low** for an absence claim.
- The first-party Agent Skills references checked were the [Agent Skills specification repository](https://github.com/agentskills/agentskills), [Anthropic's public skills repository](https://github.com/anthropics/skills), [Vercel's official agent-skills collection](https://github.com/vercel-labs/agent-skills), and [Google's Agent Skills repository](https://github.com/google/skills). These establish the relevant public repositories and `SKILL.md` convention, but they do not provide a verified identity link to the woman in the X video. Confidence: **High** for repository ownership and purpose; **unresolved** for authorship attribution.

### Follow-up: `poteto` username search

Accessed: 2026-08-28.

- The public X profile [`@poteto`](https://x.com/poteto) is named **lauren** and publicly associates the account with software engineering, Cursor, and the React Compiler team. The public GitHub profile [`poteto`](https://github.com/poteto) uses the same displayed name, links to X `@poteto`, and pins the official [`cursor/plugins`](https://github.com/cursor/plugins) repository. Together these are strong cross-link evidence for one public tech identity. Confidence: **High** for the cross-link; **not evidence** that this person appears in the Control Glass video.
- The official Cursor [`plugins` repository](https://github.com/cursor/plugins) lists `pstack` as authored by Lauren Tan. Its [official plugin manifest](https://github.com/cursor/plugins/blob/main/pstack/.cursor-plugin/plugin.json) names Lauren Tan, declares `skills: ./skills/`, and includes the keyword `poteto-mode`. The [official pstack README](https://raw.githubusercontent.com/cursor/plugins/main/pstack/README.md) says "i'm poteto," links to `https://x.com/poteto`, and describes the bundled engineering skills. The [official `poteto-mode` skill](https://raw.githubusercontent.com/cursor/plugins/main/pstack/skills/poteto-mode/SKILL.md) is publicly present. Cursor's [official marketplace page](https://cursor.com/marketplace/cursor/pstack) labels pstack "Created by Cursor," "Verified by Cursor," and containing 45 skills. Confidence: **High** that Lauren Tan publicly authored or maintains Agent Skills in this official GitHub-hosted Cursor plugin.
- Exact `poteto` and plausible X variants were checked. The exact [`@poteto`](https://x.com/poteto) profile is the only strong candidate. [`@poteto_`](https://x.com/poteto_), [`@_poteto`](https://x.com/_poteto), [`@poteto__`](https://x.com/poteto__), [`@poteto1`](https://x.com/poteto1), [`@poteto01`](https://x.com/poteto01), [`@poteto123`](https://x.com/poteto123), [`@potetoai`](https://x.com/potetoai), and [`@potetolab`](https://x.com/potetolab) displayed unrelated Japanese, empty, or protected accounts. [`@poteto_glass`](https://x.com/poteto_glass), [`@potetoglass`](https://x.com/potetoglass), [`@potetomedia`](https://x.com/potetomedia), and [`@poteto_tv`](https://x.com/poteto_tv) were unavailable or not found. Confidence: **Medium** for these public-page observations; they do not identify the video woman.
- No inspected Control Glass company or campaign page mentions `poteto`. The official site search returned no result, as did the [WordPress search endpoint](https://www.controlglass.com/wp-json/wp/v2/search?search=poteto&per_page=100). The [GitHub repository search for `poteto` and `Control Glass`](https://github.com/search?q=%22poteto%22+%22Control+Glass%22&type=repositories) and the [search for `controlglass` and `Lauren Tan`](https://github.com/search?q=%22controlglass%22+%22Lauren+Tan%22&type=repositories) returned zero repositories. Confidence: **High** for these observed results; they are negative search evidence, not proof of no connection.
- No available first-party source reveals a different username spoken by the woman. Because the original X post/video URL, transcript, and speaker credit remain unavailable, the woman's username is **unresolved**. No appearance-based identification was made.

## Limitations

- The original X URL, post author, quoted text, and any frame or transcript supplied by the user were unavailable. A different X post could refer to a different person or organization.
- The available first-party pages do not credit the person shown in the video. Identifying her from appearance alone would be unreliable and is intentionally not done here.
- The official campaign's embedded YouTube upload is currently unavailable through the public YouTube page. The official site's API record confirms the historical embed but does not add a speaker credit.
- GitHub's public profile and repository searches are not exhaustive identity resolution. Handles can differ from names, repositories can be private, and unauthenticated code search is limited. GitHub code search for `poteto` plus `Control Glass` required login and was not usable, so it is a limitation rather than a negative result.
- X anonymous profile/search access was intermittently throttled. The variant observations are therefore limited to the public pages that were accessible and are not exhaustive.
- "No public Agent Skills found" must not be read as "the woman has no skills." The defensible conclusion is narrower: **Lauren Tan has public Agent Skills authorship, but no public Agent Skills authorship can be tied to the unidentified woman in the Control Glass video**.
