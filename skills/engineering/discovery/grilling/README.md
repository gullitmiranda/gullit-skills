# grilling

A locally maintained grilling skill. Same design-tree / frontier loop as
upstream, with a readable question card so options and suggestions stay
scannable.

## Origin

This skill is derived from Matt Pocock’s
[`grilling`](https://github.com/mattpocock/skills/tree/main/skills/productivity/grilling).

The local version keeps the interview loop and replaces the one-line
`Q` / arrow template with [question-format.md](question-format.md).

## Dependencies

This skill is self-contained. `SKILL.md` references
[`question-format.md`](question-format.md). Keep that file alongside
`SKILL.md` if the skill is moved or copied.

## Upstream relationship

This copy is maintained independently and is not automatically synchronized
with the upstream skill. Review upstream changes deliberately before adopting
them here.
